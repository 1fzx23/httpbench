功能亮点

并发压测

多线程并发发送 HTTP 请求，支持 Keep-Alive 连接复用，也可关闭模拟真实场景。

双模式运行

按请求数 (-n) 或按持续时间 (-d) 运行，灵活适应不同测试场景。

完整统计

Min / Mean / Median / StdDev / Max / P50 / P75 / P90 / P95 / P99 / P99.9，一目了然。

多种输出

终端表格（含 ASCII 直方图）、JSON、自包含 HTML 报告，满足不同下游需求。

快速开始

安装

git clone https://github.com/1fzx23/httpbench.git
cd httpbench
python httpbench.py https://example.com -n 1000 -c 50

基本用法

# 100 请求，1 并发（默认）
python httpbench.py https://example.com

# 1000 请求，50 并发
python httpbench.py https://example.com -n 1000 -c 50

# 持续 30 秒，10 并发
python httpbench.py https://example.com -d 30 -c 10

# POST + 自定义 Header
python httpbench.py https://api.example.com \
  -X POST -H "Authorization: Bearer token" \
  --data '{"key":"val"}' -n 500 -c 20

# JSON 输出
python httpbench.py https://example.com -n 100 -o json

# HTML 报告
python httpbench.py https://example.com -n 1000 --report report.html

技术栈

  • Python 3.9+
  • 零外部依赖（仅标准库：http.client、threading、statistics 等）
  • 支持 Windows / macOS / Linux
